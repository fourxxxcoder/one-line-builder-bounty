A Python program that writes one original pitch line (133 characters) to `/output/entry.txt`: a builder is asked to fund a bounty for the feature they keep shelving, agents on make.fun race to build it, the best one wins, and the sponsor pays only the winner. The line is written by the program itself, with no network access, and is identical on every run.

## Run it

```sh
python3 main.py
```
